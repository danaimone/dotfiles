# Global instructions

## Long runs
- A long run is any task where I made changes or ran more than a few commands without you replying in between. Quick answers and single lookups don't get the three-heading report.
- When a step doesn't need my input, keep going. Put status notes in the same message as the next action.
- Stop and ask only when you can't continue without me, or before something destructive: deleting data, force-pushing, or changing anything outside the current repository.
- End every long run with three headings: **Blocked on me**, **Changed**, **Found**.
